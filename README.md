# Tuffsteel Limited - Nyumba Cement Landing Page

High-converting, mobile-optimized "Under Construction / Coming Soon" landing page for **Nyumba Cement Limited** in association with **Tuffsteel Limited** (Mombasa Road, Nairobi, Kenya).

## 🚀 Live Site
- **GitHub Pages:** [https://kasumbaelijah.github.io/tuffsteel/](https://kasumbaelijah.github.io/tuffsteel/)

## 🏗️ Features
- **Clean Industrial Aesthetic**: Charcoal and slate surfaces with safety amber accents.
- **Official Branding & KEBS Certification**: High-resolution Tuffsteel Superstore logo and KEBS Diamond Mark quality certification (`KS EAS 18-1`).
- **One-Tap Conversion (Mobile Optimized)**:
  - Direct **WhatsApp Order** button with pre-filled Bill of Quantities request.
  - Direct **Call Sales Desk** button (`+254 790 200 200`).
  - Mobile sticky bottom action bar for construction managers on site.
- **Fast Order Configurator**:
  - Interactive selection between **50kg Bags** and **Bulk Cement Tankers**.
  - Dynamic grade selection (**32.5R** vs **42.5N**), quantity, and delivery destination.
  - Generates pre-formatted WhatsApp message for instant sales turnaround.
- **Real Distribution Center Photography**: Authentic photos of the Tuffsteel Mombasa Road depot, loading bay, and delivery fleet.
- **Dynamic Light / Dark Mode**: With `localStorage` persistence and OS preference detection.

## 📦 Stack
- HTML5
- Tailwind CSS (CDN)
- Vanilla JavaScript
